# S. Arun — Animated Graph-Paper Portfolio

This version follows the supplied bermawy.com screenshots more closely:
- Reduced empty space above “hi there”
- Blue graph-paper background, blue typewriter-style headings, and rough torn-paper profile panel
- Portrait in the left column and concise introduction on the right
- Gentle paper entrance animation, hand-drawn underline reveal, subtle portrait float, section reveal, active navigation, scroll progress, and filterable projects
- Plain HTML, CSS, and JavaScript; no build step

## Preview
Open `index.html` in a browser. Keep `assets/arun-portrait.jpg` next to the HTML file in the `assets` folder.

## Deploy
Deploy the whole folder to Netlify, Vercel static hosting, or GitHub Pages. Review all CV/contact details before publishing.
